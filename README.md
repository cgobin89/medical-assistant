# Local Medical Assistant

A locally served medical question-answering assistant combining
LLM prompting, LoRA fine-tuning, dataset lookup, and
retrieval-augmented generation (RAG).

## Project Status

Currently setting up the local Phi-3 Mini environment.

## Planned Components

- Phi-3 Mini
- LoRA fine-tuning
- MedQuAD
- Chroma
- Retrieval-Augmented Generation (RAG)
- Local document upload
- Local chat interface
